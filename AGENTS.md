# Instructions for Coding Agents

Use [README.md](README.md) for project context and [GLOSSARY.md](GLOSSARY.md) for repository-wide terminology. This file defines how to carry out work in the repository.

## Task rules

- Make only changes within the user's requested scope. Create a `SKILL.md` only when asked to implement or revise a specific skill.
- Follow the content lifecycle and placement described in README.md.
- Keep one authoritative home for each document. Update inbound links and the README map when content moves or its location changes.
- Use repository-wide terms consistently with `GLOSSARY.md`; add or revise terms there when the user approves a terminology change.
- Follow `.editorconfig` for text formatting.

## Verification

For documentation and structure changes, check changed links and run `git diff --check`. When a skill package exists, validate it against the current Agent Skills format and the publishing tool's discovery rules.
