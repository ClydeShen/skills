Two external software systems sit outside every cloud boundary: Existing partner integrators and New partner integrators. Existing integrators call a Legacy SOAP API in Azure API Management (APIM); new integrators call a Partner SOAP API in the same APIM service. These are separate entry branches 1a and 1b, using SOAP over HTTPS and returning XML responses. Preserve both entry points.

Azure Cloud contains APIM and its two SOAP APIs, Azure AD B2C, Azure Cosmos DB for roles/permissions, and an Inbound processing software system boundary. Inbound processing contains API-Route-Processor and Common-Authx-Handler, both Logic Apps workflows, and a nested sub-workflows group containing Amend-Order-Processor and Amend-Document-Processor, also Logic Apps workflows. AWS Cloud contains API Gateway and a Core platform software system boundary containing Validation engine, an AWS Lambda function. An explicit site-to-site VPN joins the clouds; all stated Azure-to-AWS amend API traffic uses that connection.

APIM authenticates incoming requests against Azure AD B2C. The synthetic scenario specifies either basic or bearer authentication input; do not invent the token-exchange implementation or claim that Azure AD B2C natively exposes a Basic authentication protocol. APIM separately checks the system account's roles and the mandatory presence of a user profile for amend requests. It then passes the authenticated request to API-Route-Processor. API-Route-Processor delegates authorization to Common-Authx-Handler. The handler queries Cosmos DB using system account name and user profile name to check the required user-profile role. APIM's system-account role check and the handler's user-profile role check are distinct controls.

After authorization, routing is by method: amend_order goes to Amend-Order-Processor and requires ManageOrders; amend_document goes to Amend-Document-Processor and requires ManageDocuments. A user profile is mandatory for both amendment methods. Show this method-to-role mapping as a small architectural authorization table. There is no universal ManageOrders requirement for amend_document.
