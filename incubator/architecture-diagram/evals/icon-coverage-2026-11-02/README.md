# Icon coverage check: non-cloud vendors

Date: 2026-11-02. The owner asked which components beyond AWS, Azure and Google Cloud the skill can draw with a real icon, using artwork that travels with the skill and one display standard. [icon-sheet.png](./icon-sheet.png) shows every available icon, built by [generate.mjs](./generate.mjs) through the package's own lookup, placement and embedding, and rendered by the package's `render.mjs` with draw.io Desktop 32.6.1 from [icon-sheet.drawio](./icon-sheet.drawio). [icon-sources.json](./icon-sources.json) records each placement and its source. Background and licences: [vendor icon sources](../../../../research/diagrams/architecture-diagram/vendor-icon-sources-2026-11-02.md).

## Sources, in order of preference

1. draw.io vendor libraries in the package catalog: Kubernetes resources, Azure DevOps, Apigee, and the cloud-hosted variants of OpenShift, VMware, Databricks, Kafka and Grafana.
2. The vendor's own package: `@fabric-msft/svg-icons@11.1.0` for Microsoft Fabric.
3. `@thesvg/icons@4.0.0` for the rest, using the light-background variant where one exists.

The second and third tiers ship in the package as `assets/vendor-icons.json`, generated by [build-vendor-icons.mjs](../../tools/README.md#vendor-icons). Every SVG is upstream artwork, unchanged; for VMware and Splunk only the `viewBox` is tightened.

## Result

109 icons for 23 vendors render at the standard placement: symbols in a 72-unit square, wide marks 40 high, captions below in 16-point text. One component has no usable icon:

- GitHub Pages: the only available mark is a small "GitHub Pages" text. It uses the plain-box fallback.

Coverage limits:

- Most vendors have one brand mark. Product-level icons exist for Kubernetes (39 resources), Microsoft Fabric (22 workloads and items), HashiCorp (Vault, Consul, Nomad, Packer, Vagrant, Waypoint), GitHub (Actions, Copilot, Codespaces), Grafana (Loki, Prometheus) and Cloudflare (Workers, Pages, Workers AI).
- Not found: HashiCorp Boundary, Grafana Tempo and Mimir, Azure Boards, Repos, Pipelines and Artifacts, Confluent Cloud products, Splunk and Dynatrace products.
- MuleSoft, Confluent, VMware and Splunk are wordmarks; the mark replaces the name in the caption.

The browser renderer was checked separately on a small diagram with embedded icons, a wordmark and the fallback; the sheet itself exceeds that renderer's 4000-unit page bound. An unembedded vendor icon is rejected before rendering.
