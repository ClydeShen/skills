# Icon coverage check: platform and AI vendors

Date: 2026-11-02. The owner asked which components beyond AWS, Azure and Google Cloud the skill can draw with a real icon, using artwork that travels with the skill and one display standard. [generate.mjs](./generate.mjs) builds two sheets through the package's own lookup, placement and embedding, and the package's `render.mjs` renders them with draw.io Desktop 32.6.1:

- Platform vendors: [icon-sheet.png](./icon-sheet.png) from [icon-sheet.drawio](./icon-sheet.drawio).
- AI providers and tooling: [ai-icon-sheet.png](./ai-icon-sheet.png) from [ai-icon-sheet.drawio](./ai-icon-sheet.drawio).

[icon-sources.json](./icon-sources.json) records each placement and its source. Background and licences: [vendor icon sources](../../../../research/diagrams/architecture-diagram/vendor-icon-sources-2026-11-02.md).

## Sources, in order of preference

1. draw.io vendor libraries in the package catalog: Kubernetes resources, Azure DevOps, Apigee, AWS Bedrock and AgentCore, Microsoft Foundry and Azure AI, Vertex AI, and cloud-hosted variants such as Azure Databricks and Amazon MSK.
2. The vendor's own package: `@fabric-msft/svg-icons@11.1.0` for Microsoft Fabric.
3. `@thesvg/icons@4.0.0`. Its variant names are inconsistent, so AI entries name the variant chosen by eye.
4. Official project repositories pinned to a commit, for marks no package carries: A2A, Google Agent Development Kit, AutoGen, Weaviate, and the PNG marks of Semantic Kernel and Microsoft Agent Framework.

Tiers 2 to 4 ship in the package as `assets/vendor-icons.json`, generated by [build-vendor-icons.mjs](../../tools/README.md#vendor-icons). Every image is upstream artwork, unchanged; for VMware and Splunk only the `viewBox` is tightened.

## Result

All icons render at the standard placement: symbols in a 72-unit square, wide marks 40 high, captions below in 16-point text. 109 platform placements and 47 AI placements; the following have no usable icon and use the plain-box fallback:

- GitHub Pages: the only mark is a small text.
- OpenAI Agents SDK: its official logo is white artwork for dark pages; recolouring it would modify it.
- Claude Agent SDK: no dedicated mark.

Use the parent brand mark with a precise caption, or the fallback, for products without their own mark: Palantir AIP (Palantir), Salesforce Agentforce (Salesforce), NVIDIA NIM (NVIDIA). theSVG's `nim` icon is the Nim programming language, not NVIDIA NIM.

Other coverage limits:

- Most platform vendors have one brand mark. Product-level icons exist for Kubernetes (39 resources), Microsoft Fabric (22 workloads and items), HashiCorp, GitHub, Grafana, Cloudflare, LangChain (LangGraph, LangSmith), Anthropic (Claude, Claude Code) and Microsoft Foundry.
- Not found: HashiCorp Boundary, Grafana Tempo and Mimir, Azure Boards, Repos, Pipelines and Artifacts, Confluent Cloud products, Splunk and Dynatrace products.
- MuleSoft, Confluent, VMware and Splunk are wordmarks; the mark replaces the name in the caption.

The browser renderer was checked separately on a small diagram with embedded icons, a wordmark and the fallback; the sheets exceed that renderer's 4000-unit page bound. An unembedded vendor icon is rejected before rendering.
