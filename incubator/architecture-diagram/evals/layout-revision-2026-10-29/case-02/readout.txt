Architectural contracts and notes

Transit Gateway attachments are listed as ingress VPC, inspection VPC, and egress VPC. Transit Gateway/VPC routing details beyond the depicted forwarding path are explicitly unspecified.
The interface VPC endpoint is the private entry to the API Gateway APIs. Route 53 performs DNS resolution; no Route 53 outbound endpoint is retained. Route 53 resolver endpoints do not forward HTTPS.
DNS queries pass AWS Network Firewall in this fixture. API access remains subject to each API resource policy.
Both {region} and {Route 53 inbound endpoint IPs} are supplied parameters.

A firewall allowances note applies to BOTH Azure Firewall and AWS Network Firewall. It specifies these environment/source/destination/port contracts:
- dev | dev spoke subnet | Route 53 inbound endpoint IPs | 53.
- test | test spoke subnet | Route 53 inbound endpoint IPs | 53.
- prod | prod spoke subnet | Route 53 inbound endpoint IPs | 53.
- dev / test / prod | corresponding spoke subnet | *.execute-api.{region}.amazonaws.com | 443.
