# Final rewrite check

Check each applicable criterion before returning the result. Revise failed criteria.

| Criterion | Pass condition |
| --- | --- |
| Meaning | The same claim, request, warning, decision, responsibility, and uncertainty remain. |
| Protected text | Safety instructions, legal scope, technical identifiers, numbers, commands, and citations satisfy [Verbatim Preservation](rewrite-playbook.md#verbatim-preservation). |
| Terminology | Technical terms retain their meaning and spelling; project term preferences are applied. Ordinary verbs stay plain. |
| AI patterns | Residue is repaired; padding, mechanical repetition, vague authority, and decorative structure are resolved. Useful contextual exceptions remain. |
| Evidence | Every specific detail comes from the source or supplied evidence. Unresolved source problems remain visible. |
| Voice | Wording and rhythm follow applicable profile rules; channel defaults fill gaps. |
| Occasion | Structure, courtesy, detail, and closing suit the audience and format. |
| Flow | Sentences connect naturally, each passage adds information, and the text ends when its job is done. |
| ASD-STE100 | When selected, the output follows the applicable standard or is identified as inspired output under [asd-ste100.md](asd-ste100.md). |

For a review, check the accuracy of each diagnosis and proposed edit. Apply rewrite criteria to the proposed edits.
