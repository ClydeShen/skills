# Human-AI Meta Thinking 研究

本目录保存人和 AI 如何选择、检验和切换思考方式的原始材料、证据及探索记录。当前综合指导见 [Meta Thinking 知识目录](../../../knowledge/meta-thinking/README.md)。

## 材料

- [原始探索草稿](./meta-ai-thinking-working-draft-2026-10-25.md)：用户提供的 PRD-style Working Draft 的 Markdown 归档，保留背景、需求、层级假设、示例和开放问题。文件名日期表示归档日期。
- [计算、协作与自动化基础](./metareasoning-foundations-2026-10-25.md)：元思考成本、停止条件、主动介入及分工维度的一手来源与研究假设。
- [抽象、批评与协作的证据边界](./interaction-evidence-and-evaluation-2026-10-25.md)：正反实验结果、适用限制和下一轮对照案例建议。
- [轻量干预与目标探索](./lightweight-intervention-2026-10-25.md)：保存后续需求澄清，调查偏好形成、干预负担、简单设计与隐式激活边界。
- [事件触发记忆与用户画像](./event-driven-memory-2026-10-25.md)：调查事件证据、lazy 更新、归因限制、时序修正与选择性样本问题。
