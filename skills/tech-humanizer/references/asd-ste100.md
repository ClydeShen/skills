# ASD-STE100

Use this mode when the user requests ASD-STE100 or an applicable project specification requires it.

ASD-STE100 Simplified Technical English defines writing rules and a controlled dictionary for technical documentation. Issue 9 was released on 2025-01-15. It permits subject-specific technical nouns and verbs.

## Apply

Read the applicable issue of the [official standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) and the project's terminology requirements.

After AI-style cleanup, apply the standard's vocabulary and sentence rules. Apply user voice preferences within those requirements. Preserve technical meaning, factual detail, and safety conditions.

For an ASD-STE100-inspired rewrite:

- Use words consistently in meaning and part of speech.
- Write short, direct sentences.
- Put one instruction in each procedural sentence.
- Use active voice in procedures and put conditions before dependent actions.
- Keep warnings explicit and preserve project technical nouns and verbs.
- Follow project conventions for units, abbreviations, numbering, and typography.

Describe output as compliant only after checking the full applicable rules, dictionary, and project terminology. Otherwise identify it as `ASD-STE100-inspired`.

Sources: [official overview](https://www.asd-ste100.org/about_STE.html), [official FAQ](https://www.asd-ste100.org/STE_faq.html).
